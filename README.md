# DNA Analyser – Interactive DNA Sequence Analysis Lab

A modular Python educational project for processing DNA sequences through validation, nucleotide counting, GC/AT analysis, reverse/complement operations, motif searching, sequence comparison, transcription, basic translation and quizzes.

## Run
```bash
python main.py
```

## Tests
```bash
python -m unittest discover -s tests
```

## Modules
- DNA Sequence Lab
- DNA Analysis Lab
- Bio Quiz Lab

## CSE1021 alignment
Uses problem-solving, algorithms, functions, control flow, counting, reverse operations, searching, lists, dictionaries and sets.

## Educational scope
This is an educational sequence-processing application, not a clinical or diagnostic genetic-analysis system.

## Future scope
GUI visualization, FASTA import/export, sequence alignment, richer motif databases and complexity analysis.
