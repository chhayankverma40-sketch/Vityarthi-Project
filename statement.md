# Project Statement

## Title
DNA Analyser – Interactive DNA Sequence Analysis Lab

## Problem Statement
DNA operations are often learned as separate concepts. DNA Analyser combines common sequence-processing tasks in one interactive Python application, demonstrating how algorithms and Python data structures can process biological sequence data.

## Objectives
- Validate DNA sequences.
- Count nucleotides and calculate GC/AT content.
- Generate reverse, complement and reverse-complement sequences.
- Demonstrate transcription and basic codon translation.
- Search motifs and compare sequences.
- Provide a concept quiz.

## Functional Requirements
1. Accept and validate DNA sequences.
2. Calculate nucleotide statistics.
3. Generate sequence transformations.
4. Search motifs.
5. Compare sequences.
6. Perform basic transcription/translation.
7. Provide a quiz with score and accuracy.

## Non-Functional Requirements
Usable menus, modular maintainable code, clear validation errors, portability with standard Python, and automated tests.

## Technology
Python 3.x, JSON and unittest.

## Scope
Educational sequence processing only; no medical diagnosis or genetic-risk interpretation.
